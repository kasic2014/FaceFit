# Face-Fit Frontend

사용자 면접 연습 화면 프론트엔드 모듈입니다.

## 폴더 구조

- `src/components/`: 공통 UI 컴포넌트
- `src/pages/`: 주요 라우터 페이지 (홈, 면접 진행, 결과 페이지 등)
- `src/features/`: 기능별 도메인 컴포넌트 및 로직
- `src/services/`: 백엔드 및 AI 서버 API 연동 서비스
- `src/hooks/`: 커스텀 React 훅
- `src/assets/`: 이미지, 폰트 및 정적 리소스
- `src/utils/`: 유틸리티 함수
- `public/`: 정적 렌더링 파일
- `tests/`: 프론트엔드 테스트 코드
