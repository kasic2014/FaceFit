# Scoring validation plan V1

Before a production profile is considered, collect multiple consented sessions spanning realistic lighting, camera distance/angle, microphone type/gain, background noise, answer duration, and language/cultural context. Keep development, validation, and holdout sessions separate.

Create an observable-behavior human rubric that does not encode hiring or psychological judgments. Use trained, blinded raters; measure inter-rater and intra-rater agreement and adjudicate disagreements. Compare profile outputs with rubric observations, not employment outcomes.

Evaluate threshold and weight sensitivity, confidence intervals, missingness, coverage, repeatability, ceiling/floor effects, calibration drift, and microphone/camera effects. Audit subgroup error and missingness patterns where lawful and consented, without using protected traits as scoring inputs. Document language/cultural limits and proxy risks. A multi-disciplinary approval must review evidence, fairness, privacy, and intended-use wording before production activation.
