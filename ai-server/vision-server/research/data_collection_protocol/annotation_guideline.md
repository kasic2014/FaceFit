# 관찰 행동 라벨링 가이드

평가자는 화면에서 직접 확인 가능한 움직임과 품질 사건만 `[start, end)`로
기록한다. 머리 회전·상하 pitch·좌우 roll, 어깨선 기울기, 상반신 이동, 얼굴
및 어깨 비가시성, 다중 인물, 카메라 이동, framing 변경이 대상이다.

방향이 있는 라벨은 저장 영상 이미지 좌표의 `LEFT`, `RIGHT`, `UP`, `DOWN`
중 해당 방향을 반드시 기록한다. 품질 라벨은 방향을 기록하지 않는다. 사건은
답변 경계 안에 있어야 하고 시작은 포함, 종료는 제외한다. 동일 평가자의 완전
중복 사건은 허용하지 않는다.

자신감, 불안, 주의, 성격, 채용 적합성, 합격·불합격, 정신건강, 진단, 거북목,
척추측만증을 관찰 라벨로 추론하지 않는다. `rater_confidence`는 라벨링
확실성에 대한 fixture 필드일 뿐 사람의 자신감을 뜻하지 않는다.
