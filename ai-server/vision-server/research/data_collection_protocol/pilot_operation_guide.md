# 파일럿 운영 가이드

상태는 운영 승인 전 초안이다. 실제 모집 전에 참여자 가명 등록, 목적별 동의,
촬영 checklist, baseline과 답변 구간, 파일 메타데이터, 자동 품질 검사, 수동
검수, annotation 준비, dataset 후보 등록 순으로 진행한다.

필수 checklist가 하나라도 실패하면 `READY`로 전환하지 않는다. 각 상태 변경은
허용 전이표를 통과해야 하며 `EXCLUDED`, `WITHDRAWN`, `FAILED`는 terminal
상태다. 자동 `WARNING`은 검수 필요 신호이지 사람의 자세 불량이나 평가 결과가
아니다. 사고·철회 발생 시 사용을 차단하고 파일은 삭제하지 않은 채 격리 또는
삭제 대기 상태만 기록한다.
