# 참여자 촬영 안내 초안

이 문서는 실제 참여자용으로 승인된 안내문이 아니다. 촬영 전 영상 수집, 자동
분석, 연구 사용 목적을 각각 확인한다. 화면에는 한 명만 등장하고 얼굴과 양쪽
어깨가 포함되어야 한다. 카메라를 고정하고 조명·마이크·저장 공간을 확인한다.

중립 baseline 뒤 각 답변의 시작과 종료 timestamp를 `[start, end)`로 기록한다.
촬영 품질 문제는 재촬영 또는 제외 사유가 될 수 있지만 사용자 점수나 평가로
해석하지 않는다. 참여자는 철회를 요청할 수 있으며 실제 절차는 윤리·법무 승인
후 확정한다.
