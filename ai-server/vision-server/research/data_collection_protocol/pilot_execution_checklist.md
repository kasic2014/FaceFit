# Pilot 실행 전 체크리스트

현재 상태: **설계 초안 — 실제 수집 승인 아님**

- [ ] 기관 윤리·법무·개인정보·보안 검토 완료
- [ ] 목적별 동의 문서와 철회 절차 승인
- [ ] 가명키 분리 보관 및 접근 권한 승인
- [ ] 카메라 고정, 미러링, 해상도, 원본 FPS 기록 절차 검증
- [ ] 얼굴과 양쪽 어깨 framing 및 단일 인물 조건 검증
- [ ] baseline과 `[start, end)` 답변 timestamp 기록 검증
- [ ] 두 명 이상 독립 평가자 교육 및 blind 환경 검증
- [ ] observable-only rubric과 금지 추론 교육 확인
- [ ] 원본 A/B와 adjudicated layer 분리 보존 확인
- [ ] participant-level split leakage 검사 확인
- [ ] 보존 기간, 백업, 철회 전파, 파기 절차 승인
- [ ] 실제 영상 없이 metadata fixture smoke test 통과

모든 항목이 승인되기 전 실제 참여자 모집·촬영·annotation을 시작하지 않는다.
