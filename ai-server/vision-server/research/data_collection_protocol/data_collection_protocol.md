# Face-Fit 데이터 수집 프로토콜 초안

상태는 `DRAFT`다. 이 문서는 실제 참여자 모집이나 촬영 승인이 아니라 Stage 13
계약 모델을 검토하기 위한 연구 설계 초안이다.

수집 단위는 가명 참여자, 고정 카메라 녹화 세션, 중립 baseline, 그리고
`[start, end)` 답변 구간이다. 한 화면에는 한 명만 등장해야 하며 얼굴과 양쪽
어깨가 보여야 한다. 분석 범위는 얼굴, 코, 양쪽 귀, 양쪽 어깨로 제한한다.
팔꿈치, 손, 골반, 하체는 필수 촬영 또는 자세 분석 범위가 아니다.

모든 사용 전에 영상 수집, 자동 분석, 연구 사용, 모델 개발 목적별 동의를
확인한다. 동의가 없거나 보류·철회됐거나 목적 권한이 없으면 데이터 사용
불가로 분류한다. 이를 불리한 평가나 점수로 해석하지 않는다.

이 단계에서는 실제 사람, 영상, 직접 식별정보를 수집하지 않는다. pilot 실행
전 기관의 윤리·법무·보안 검토, 보존 기간, 철회 전파 절차를 별도로 승인받아야
한다.
