# Manual Review 체크리스트

- consent와 철회 상태 재확인
- 파일 reference, SHA-256 및 자동 검사 결과 확인
- 얼굴·양쪽 어깨·단일 인물·카메라 고정 조건 확인
- baseline 및 답변 구간 유효성 확인
- `APPROVED_FOR_ANNOTATION`, `RECORDING_REQUIRED`, `EXCLUDED`,
  `REVIEW_PENDING` 중 결정
- 운영 reason code, 검수자 가명 ID, 시각, 사실 기반 notes 기록

자신감, 성격, 태도, 불안, 의료 상태, 합격 가능성 또는 점수를 기록하지 않는다.
