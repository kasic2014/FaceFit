# 데이터 거버넌스 메모

데이터셋에는 `PTC_######` 가명 ID만 사용하고 이름, 이메일, 전화번호, 주소 등
직접 식별정보를 manifest에 넣지 않는다. 원본 영상과 식별키가 실제로 생기는
pilot 단계에서는 분리 저장, 최소 권한, 접근 로그, 암호화, 보존·파기 일정을
별도 승인해야 한다.

철회는 모든 후속 사용을 차단하는 gate다. 세션, 답변, annotation, manifest,
파생 산출물에 철회 전파가 가능한 참조 구조를 유지해야 한다. 이미 동결된
연구 데이터에 대한 처리 정책은 실제 수집 전 윤리·법무 검토가 필요하다.

DEVELOPMENT, CALIBRATION, VALIDATION, HOLDOUT 분리는 참여자 단위로 수행한다.
같은 참여자의 세션과 답변이 여러 split에 나타나면 안 된다. 이 단계의 seed와
분배는 fixture 검증용이며 실제 비율을 승인하지 않는다.
