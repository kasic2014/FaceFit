# 카메라 설정 가이드

1. 카메라를 고정하고 촬영 중 위치·방향·줌을 바꾸지 않는다.
2. 얼굴과 양쪽 어깨가 전체 답변 동안 화면 안에 있도록 1280×720 이상을
   권장하되, 실제 규격은 pilot 검증 후 확정한다.
3. 원본 FPS와 분석 FPS를 각각 기록한다. 현재 분석 계약은 5 FPS를 표현할 수
   있지만 수집 장치의 원본 FPS를 덮어쓰지 않는다.
4. 미러 preview 여부와 저장 영상의 좌우 반전 여부를 별도로 기록한다.
5. 한 명만 촬영하며 배경 인물 출현, 가림, 카메라 이동, framing 변경을 품질
   사건으로 기록한다.
6. 답변 전 중립 baseline과 각 답변의 시작·종료 timestamp를 기록한다.

방향 라벨의 왼쪽/오른쪽은 저장 영상의 이미지 좌표를 기준으로 한다. 촬영 전
동의와 철회 상태를 다시 확인한다.
