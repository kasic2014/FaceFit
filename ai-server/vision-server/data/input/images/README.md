# 정적 이미지 테스트 입력

정적 이미지 분석 CLI는 `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`를 지원한다.
확장자뿐 아니라 OpenCV 실제 디코딩 성공 여부를 검증한다.

권장 테스트 구성:

1. 정면 얼굴과 상체가 보이는 이미지
2. 고개를 왼쪽으로 돌린 이미지
3. 고개를 오른쪽으로 돌린 이미지
4. 고개를 아래로 숙인 이미지
5. 상체를 왼쪽 또는 오른쪽으로 기울인 이미지
6. 어두운 이미지
7. 얼굴이 없는 이미지
8. 얼굴 일부가 가려진 이미지

개인정보 보호를 위해 본인 또는 사용 동의를 받은 사람의 이미지만 사용한다.
파일명에는 실명, 전화번호, 이메일을 넣지 말고 익명 테스트 ID를 권장한다.
입력 이미지를 외부 공개 저장소에 업로드하지 않는다. 이 데이터는 음성 복제에
사용하지 않는다.

분석기는 파일을 로컬에서 읽을 뿐 원본을 수정하거나 외부로 업로드하지 않는다.
