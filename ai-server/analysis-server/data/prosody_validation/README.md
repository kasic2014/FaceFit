# Prosody validation dataset

이 디렉터리는 prosody v2.1 측정값의 반복성과 녹음 장치·환경 민감도를
검증하기 위한 익명 내부 데이터셋 manifest를 보관한다. 실제 이름, 연락처,
계정 식별자, 생년월일, 성별, 주소 또는 동의 문서 자체를 저장하지 않는다.

## A. 최소 파일럿

- 익명 화자 코드 1명 이상
- 장치 2종
- 동일 스크립트 2종
- 각 조건 3회 반복
- `clean`과 `natural` 조건 우선

## B. 확장 검증

- 익명 화자 코드 5명 이상
- 장치 2종 이상
- 같은 스크립트 반복 녹음
- `quiet`, `background_noise`, `fast`, `slow` 조건 포함
- clipping은 의도적으로 만든 테스트 파일에서만 제한적으로 사용

## C. 녹음 원칙

- 같은 문장을 조건별로 사용한다.
- 장치와 입 사이 거리를 `notes`에 기록한다.
- 자동 음량 보정 사용 여부를 `notes`에 기록한다.
- 녹음 후 파일을 편집하지 않는다.
- 실제 이름이나 민감정보를 파일명에 넣지 않는다.
- 화자와 장치는 각각 `SPK001`, `DEV_PC_MIC_01` 같은 익명 코드만 사용한다.
- `consent_confirmed`에는 동의 여부만 기록하고 동의 문서 자체는 저장하지 않는다.

## D. 현재 단계의 금지사항

- 수집된 표본으로 즉시 점수 임계값 설정
- 화자 간 피치 순위 비교
- 성별·연령별 기준 작성
- `unreliable` 결과를 사용자 리포트에 사용
- 적은 표본으로 정상 범위 확정

## 권장 수집 순서

1. 한 화자와 두 장치로 같은 스크립트의 `clean` 녹음을 각각 3회 수집한다.
2. 같은 구성으로 두 번째 스크립트와 `natural` 조건을 수집한다.
3. 장치·거리·자동 음량 보정 설정을 고정하고 `fast`, `slow`를 추가한다.
4. 재현 가능한 배경 소음 조건을 추가한다.
5. 파일럿 절차가 안정된 뒤 익명 화자를 5명 이상으로 확대한다.
6. clipping 검증은 별도의 의도적 테스트 파일로만 수행한다.

이 benchmark는 기존 v2.1 JSON을 읽기만 하며 STT, WAV 변환, 품질 지표 생성,
prosody 재분석을 자동 실행하지 않는다.
